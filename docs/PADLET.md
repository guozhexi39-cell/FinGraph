# Padlet material

## Title

FinGraph: A Transparent Multi-Agent Decision Workspace

## Description and target audience

FinGraph is a Python research workspace for students and beginners who want to
understand how several specialist analyses can contribute to one decision.
Fundamental, technical and news agents produce structured reports, while a decision
agent proposes an action. Independent risk rules check the proposal before a human
can approve or reject it. The dashboard exposes disagreements, portfolio
information and an event log instead of hiding the process behind a single answer.
The submitted demo uses deterministic mock data and disables orders, so it runs
without API keys. FinGraph teaches transparent decision workflows; it does not
predict profits or provide financial advice.
