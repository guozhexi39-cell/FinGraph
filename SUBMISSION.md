# Submission guide

## Ed code submission

Upload the current project using the Code Submission slide's accepted format.
Include every Python file in `app/`, `config/`, `data/`, `execution/`, `graph/`,
`nodes/`, `schemas/`, `services/`, `tests/`, and root `main.py`. Preserve package
folders and `__init__.py` files.

Also include `README.md`, `TESTING.md`, both requirements files, `.env.example`,
and the `docs/` folder. `FILES.sha256` records the packaged source files.
If Ed accepts ZIP files, `FinGraph-submission.zip` contains this complete source
folder. If it requires separate files, upload the intact source through that
interface. This guide does not submit anything to Ed.

The sibling `offline-dependencies/` directory is optional installation material,
separate from the small source archive. Check its platform notes in `TESTING.md`
and the tutor's preferred dependency-delivery method. Do not submit a local
virtual environment, credentials, an actual `.env` or generated caches.

## Padlet and presentation

The student has already confirmed tutor approval, a new project, and completion
of the Padlet post and classroom presentation. Keep the actual course records.
This folder adds reusable materials for the final version:

- Title and approximately 100-word description with target audience:
  `docs/PADLET.md`.
- Actual program screenshot: `docs/images/overview.png`.
- Three-minute demonstration outline: `docs/DEMO.md`.
- Class, recursion and testing explanations: `docs/PROJECT_NOTES.md`.

Check that the existing post includes the title, uploaded image and description,
and that the presentation meets the course's three-minute rule. The outline's
timing is a rehearsal plan rather than a measured speaking-time guarantee.

## Final review

Review the source and the actual AI-assistance record in `docs/PROJECT_NOTES.md`.
Apply the course's assistance and acknowledgement rules; no policy permission or
unaided-authorship claim is invented here. Verify the correct tutorial board,
all Ed files and the submission receipt. No student name, ID or approval record
has been fabricated.
